# 京东 Cookie 提取器

多账号安卓工具：用 **独立 WebView 会话** 登录自己的京东账号，自动提取 `pt_key` / `pt_pin`，并支持本地 CK 检测与可选青龙推送。

> Cookie 默认只保存在本机。请勿泄露给他人。

## 功能（v1.7.0）

- **Cookie 失效提醒**
  - 更新 / CK 检测后，失效账号卡片显示红色「失效」角标，顶部横幅列出失效账号
  - 系统通知渠道「京东CK提醒」（Android 13+ 需 `POST_NOTIFICATIONS`），点击打开应用
  - 设置项「失效时通知」（默认开启）
  - 推送到青龙若变量仍为禁用（常因 CK 失效被脚本禁用），同样弹出提醒
- **养号模式**、**京豆卡片内嵌**、**一键更新**、登录后自动推送青龙等（见往期版本）

## 使用

1. 安装 Release APK
2. 菜单 → 青龙配置：填写 OpenAPI，按需开启养号模式 / 失效时通知
3. 添加账号并登录；点「更新」刷新 CK / 京豆 / 推送状态

## 构建

```bash
./gradlew assembleRelease
```

签名密钥放在仓库外，切勿提交。

## 注意

- 仅供个人使用
- minSdk 24 / targetSdk 34
