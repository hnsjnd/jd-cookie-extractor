# 京东 Cookie 提取器

多账号安卓工具：用 **独立 WebView 会话** 登录自己的京东账号，自动提取 `pt_key` / `pt_pin`，并支持本地 CK 检测与可选青龙推送。

> Cookie 默认只保存在本机。请勿泄露给他人。

## 功能（v1.6.0）

- **账号列表主界面**：昵称 / pt_pin、有效/失效状态、最近更新时间
- **京豆信息直接显示在账号卡片**：余额 / 今日增加 / 即将过期；顶部合计汇总
- **「更新」一键刷新全部账号**：CK 有效性 + 京豆 + 青龙推送状态；并发上限 2；本地缓存
- **养号模式**（青龙配置里开关）：开启后减少激进跑任务提示，账号标记为养号；推送到青龙时备注前缀 `[养号]昵称` 便于筛选。关闭后恢复普通推送。不提供、不伪造任何「解黑」接口。
- **添加账号**：独立 WebView 会话，账号互不串号；登录后自动提取并推送到青龙
- **任务进度**：批量 CK 检测；可选拉取青龙 cron 列表
- **应用内青龙面板**与 OpenAPI 推送 / 更新 `JD_COOKIE`

## 使用

1. 安装 Release APK
2. 菜单 → 青龙配置：填写 OpenAPI，按需开启 **养号模式**
3. 点右下角添加账号并登录
4. 点右上角 **更新** 刷新全部账号

## 构建

```bash
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

签名密钥放在仓库外，切勿提交。
